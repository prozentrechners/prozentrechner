# Prozentrechner

Kostenloser Open-Source-Prozentrechner für Schule, Beruf und Alltag. Berechnet Prozentwert,
Prozentsatz und Grundwert — inklusive Rechenweg, direkt im Browser, ohne Anmeldung.

## Funktionen

- Prozentwert berechnen: W = G × p ÷ 100
- Einfache, werbefreie Oberfläche auf Deutsch
- Läuft komplett lokal im Browser (keine Datenübertragung)

## Verwendung

`index.html` im Browser öffnen, Grundwert und Prozentsatz eingeben, auf „Berechnen“ klicken.

## Webversion

Die vollständige Version mit Rabattrechner, Mehrwertsteuer-Rechner und prozentualer
Veränderung gibt es auf [prozentrechners.de](https://www.prozentrechners.de/).
